---
name: Local legal-agent trust boundary
description: Safety boundary that must precede computer use or privileged client-data handling.
---

The legal agent may use read-only, matter-scoped retrieval first. Computer use, external transmission, irreversible writes, and cloud fallback must remain disabled until the Mac runtime enforces isolation, explicit attorney approval, and tamper-evident auditing.

**Why:** The inherited Constellation Relay tool loop executes model-selected tools directly and does not isolate memory by client or matter. That is unsuitable for privileged legal materials.

**How to apply:** Add capabilities in this order: local cited retrieval, typed read-only tools, approval-gated writes, then sandboxed browser/computer use. Never present the hosted prototype as proof that client data is already local or encrypted.
